# Voxa - AI Translator

Voxa is a modern, real-time translation web application that enables seamless communication between speakers of different languages. Using advanced speech recognition, AI translation, and text-to-speech capabilities, voxa provides a smooth and interactive translation experience.


## Features

- Real-time speech recognition and translation
- Support for multiple languages (English, Hindi, Arabic, German, Spanish, Japanese, Chinese)
- Natural text-to-speech output with female voice preference
- Modern, responsive UI with smooth animations
- Seamless back-and-forth conversation support
- Language swap functionality
- Powered by Google's Gemini AI for accurate translations

## Technologies Used

- HTML5
- CSS3 (with modern animations)
- JavaScript (ES6+)
- Web Speech API
- Google Gemini API
- Space Grotesk Font

## Getting Started

### Prerequisites

- Modern web browser (Chrome recommended for best speech recognition support)
- Google Gemini API key
- Basic knowledge of HTML/CSS/JavaScript


## Usage

1. Select your "From" and "To" languages from the dropdown menus
2. Click the microphone button to start
3. Speak in your selected language
4. The app will:
   - Recognize your speech
   - Translate it to the target language
   - Speak the translation
5. The other person can then speak in their language, and the process continues
6. Click the microphone again to stop the translation session
